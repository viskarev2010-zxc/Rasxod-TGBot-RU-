# 💸 Budget & Focus Bot

Telegram-бот, который помогает держать под контролем расходы и не забывать про перерывы: учёт трат одной строкой и Pomodoro-таймер прямо в чате.

## ✨ Возможности

- **Быстрая запись трат** — просто отправьте `кофе 250`, бот сам разберёт название и сумму.
- **Доходы** — добавьте плюс в начале: `+зарплата 50000`.
- **Категории кнопками** — Еда, Транспорт, Развлечения, Другое.
- **Статистика** — баланс и сумма расходов за текущий месяц.
- **Pomodoro 25 минут** — таймер фокуса с уведомлением о завершении.
- **Статистика фокуса** — сколько сессий и минут набралось за день.

## 🛠 Стек

- Python 3.11+
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- SQLite + [aiosqlite](https://aiosqlite.omnilib.dev/) — локальное хранение данных
- python-dotenv — конфигурация через `.env`

## 🚀 Запуск за 3 шага

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Токен: скопируйте .env.example в .env и вставьте токен от @BotFather
copy .env.example .env        # Windows (Linux/macOS: cp .env.example .env)

# 3. Запуск
python main.py
```

Бот работает через long polling; база `bot.db` создаётся автоматически при первом старте.

> Токен можно получить у [@BotFather](https://t.me/BotFather): `/newbot` → имя → токен вида `123456:ABC...`.

```

│   ├── keyboards/
│   │   └── main_kb.py      # Reply-меню и inline-кнопки
│   └── services/
│       └── timer.py        # асинхронный Pomodoro-таймер
├── requirements.txt
└── .env.example
```
